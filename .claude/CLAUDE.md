# Claude 專案行為準則 (Guardrails - Security Enhanced)

## 絕對禁止 (Strict Read-Only)
1. **核心邏輯保護**：除非我明確指示，否則嚴禁修改任何檔名包含 `strategy`, `calculator`, `vcp`, `rs_logic` 的檔案。這些檔案對 Claude 僅具備「唯讀」權限。
2. **網站核心設定**：除非我明確指示，否則嚴禁更動 `docusaurus.config.js`, `sidebars.js` 或 `package.json`。
3. **資料庫安全**：除非我明確指示，否則禁止直接對正式資料庫（如 `.db`, `.sqlite`）進行 `UPDATE` 或 `DELETE` 操作。
4. **更改後回報**：若經我明確指示後，有對上述檔案進行修改，請在修改後清楚回報修改了哪些檔案，還有進行了哪些改動，以及會造成的影響。

## 沙盒執行規範 (Sandboxing)
1. **強制作業區域**：所有新撰寫的 Python 抓取腳本、測試代碼，必須存放於 `temp_scripts/` 資料夾下。
2. **命名規範**：新建檔案格式為 `YYYYMMDD_任務名稱_tmp.py`，嚴禁使用與現有檔案衝突的名稱。
3. **獨立輸出**：抓取到的數據（RS 排名等）一律存為 `output/` 下的獨立 `.csv` 或 `.json`，不得覆蓋舊資料。

## 自動化行為 (For Bypass Mode)
- **減少確認次數**：在執行非破壞性的 Bash 指令（如 `ls`, `cat`, `python run_test.py`）時，請盡可能一次性完成，不要拆散步驟詢問。
- **預設同意**：對於新建立在 `temp_scripts/` 資料夾內的檔案修改，請視為已獲得完全授權。
- **錯誤處理**：若執行腳本報錯，請嘗試在 `temp_scripts/` 內修復。若涉及修改原始碼才能修復，請立即停止並等待我回來處理。
- **背景執行**：在 `Bypass` 模式下，請保持作業安靜。完成後彙整「新建檔案清單」與「執行結果摘要」即可。

## 溝通風格
- 嚴禁擅自解釋或美化數據，當你的信心低於 85%，請直接跟我說你不知道。
- 請保持研究的客觀性。
